# Fake Review Detection using DistilBERT

This project explores fake review detection using traditional machine learning, deep learning, and transformer-based approaches. The primary focus is on evaluating the effectiveness of DistilBERT for detecting deceptive reviews in e-commerce platforms.

## Overview
- Detects fake vs real reviews from textual data
- Uses transformer-based NLP techniques
- Compares DistilBERT with models like Naive Bayes, SVM, CNN, and LSTM
- Evaluated using Precision, Recall, and F1-score metrics

## Dataset
- Amazon Fake Reviews Dataset
- 40,000+ reviews
- Balanced distribution of fake and genuine reviews

## Technologies Used
- Python
- TensorFlow / PyTorch
- Hugging Face Transformers
- DistilBERT
- Scikit-learn
- Pandas, NumPy

## Results
DistilBERT achieved superior performance compared to traditional ML and earlier deep learning models:
- Precision: 0.96
- Recall: 0.99
- F1-score: 0.97

## Key Features
- Context-aware fake review detection
- Transformer-based text understanding
- Efficient and lightweight DistilBERT implementation
- Comparative performance analysis
